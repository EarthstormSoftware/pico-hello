Clock

The time zone is the standard (winter) offset; summer time adds an hour. Europe: last Sunday of March to last Sunday of October. North America: second Sunday of March to first Sunday of November.

Web Access

A password is set.

With a password set, the browser asks for it (any username), and updates over Wi-Fi can be sent. It's sent unencrypted, so it keeps out other people on your network rather than a determined attacker. Setup mode removes a forgotten one.

Diagnostics

Name

Also its network name (name.local) and MQTT client id. Home Assistant names its entities after it. Letters, digits, - and _; used from the next start.

Updates

deploy.ps1 -WiFi <name> sends a new version over Wi-Fi (with a web password set): the device tries it, and goes back to this one if it doesn't start properly.

Restart and Reset

Reset puts every setting on these pages back to its default (the web password too), but keeps the Wi-Fi network. A factory reset also forgets the name and Wi-Fi, and starts setup mode.

Wi-Fi Network

Connected to …. A new network is used after a restart, on trial: if it can't connect within 5 minutes, the device goes back to this one.

Setup mode is the other way, with no network to reach this page: the device's PicoHello-SETUP hotspot and a page at http://192.168.4.1. Holding BOOTSEL for 5 s starts it, as does the fallback below.

Connecting

MQTT lets home automation software such as Home Assistant or Node-RED read and change the greeting.

Broker

A password is set.

Topics

{name} becomes the device name. The greeting is on <base>/state, and {"greeting": "..."} on <base>/set changes it. Topics no longer used are cleared from the broker after the restart.

Home Assistant

Home Assistant adds the greeting automatically (MQTT discovery), as a text box. Turning this off removes it again. Only change the prefix if Home Assistant's has been changed.
